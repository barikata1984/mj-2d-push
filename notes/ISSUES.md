# ISSUES

## 座標系の不一致

UR5e base body に `quat="0 0 0 -1"` が設定されており, base link の y 軸がワールド -y 方向を向く. 現在のシミュレーションはワールド +y 方向にプッシュしているため, base link 基準では -y 方向のプッシュになる. session_summary の仕様(base link y 軸沿いに 0.2→0.8)と整合させるには符号の整理が必要.

## MuJoCo 接触ソルバ由来の θ 振動

スライダの θ に ±0.3° 程度の高周波振動が観測される. 準静的解析(Stage 0)では θ は滑らかに推移するため, これは MuJoCo の接触力解法に起因する. `solref`/`solimp` パラメータの調整, または接触ソルバの種類(`elliptic` cone)の変更で改善の余地がある.
