# ISSUES

## MuJoCo 接触ソルバ由来の θ 振動

スライダの θ に ±0.3° 程度の高周波振動が観測される. 準静的解析(Stage 0)では θ は滑らかに推移するため, これは MuJoCo の接触力解法に起因する.

接触パラメータ感度分析 (`experiments/exp_contact_sensitivity.py`) の結果:
- `solref`/`solimp` の調整効果は限定的
- **elliptic cone が必須** — pyramidal cone では振動 42° に達しプッシュ失敗
- `mu_pusher` = 0.1 で振動 2.8° に増大 (デフォルト 0.3 で ~0.5°)
- 現在の設定 (elliptic, µ=0.3, solref=0.02) は安定動作の最適近傍

→ 振幅 ±0.3° は本系のソルバ残差として許容可能. 定量比較では平滑化フィルタを適用すること.

## 鉛直 pusher: 残存する x ドリフト・θ 回転

tool0 を鉛直下向きにした vertical pusher で 2D 押しは成功 (base 0.4→0.8 到達, 接触維持, 姿勢保持) するが, スライダが序盤に θ≈13.7° 回転し, それに伴い x が線形に −7cm ドリフトする (2026-06-04 時点; `results/20260604_055553`).

原因:
- MPC は接触点を `gripper_pinch` (閉じた指の中心線) と仮定するが, 実接触は閉じた指の前面 (world +y 側にオフセット) で発生. この食い違いで MPC の θ/x 補正が正しく効かない
- tilt が一定値で落ち着くのは, 誤モデル下で MPC が「補正済み」と誤認する平衡に入るため

対策候補:
1. MPC 接触点を実接触点 (指前面オフセット) に補正
2. 接触点が pinch に一致するようグリッパ/プッシャ形状を調整
