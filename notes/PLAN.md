# PLAN

## 実験の段階構成

session_summary.md §3.7 のラダーに従う:

1. **2D プッシュ**(CoM_xy + c の整合) ← Stage 1+ 完了
2. 質量が効く課題(力計測 or 加速を伴う押下/持ち上げ)
3. MoI が効く課題(回転動力学・スピン・動的プッシュ)

## Stage 1+ 完了時点の知見

- Stage 0 (解析) と Stage 1 (MuJoCo) の Δθ 傾向は高相関 (r=0.998), 定量的には MuJoCo が ~69% の回転量
- CoM A/B/C 対照は MuJoCo でも成立 (A > B ≈ C). MPC フィードバックが差を縮小する
- elliptic cone が準静的プッシュに必須. 摩擦・接触パラメータの感度は低い
- 準静的仮定の実用的上限は ~0.20 m/s. 0.35 m/s 以上で明確に破綻
- 非一様圧力分布: 押し方向と直交する CoM シフトが支配的. c 補正のみでは不十分

## Stage 2 への移行条件

Stage 1+ の結果から, 2D プッシュにおける CoM 推定の妥当性は確認済み. 次段階 (質量が効く課題) への移行には:

1. 力/トルクセンサの導入 (MuJoCo の `sensor` 要素)
2. 動的な押し/持ち上げタスクの定義
3. 質量推定器の設計 (CoM 推定を拡張)
